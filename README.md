# Arduino Ultrasonic Parking Sensor

مشروع حساس ركن (Parking Sensor) باستخدام Arduino Uno وحساس المسافة فوق الصوتية HC-SR04، مع مؤشر LED Bar Graph، وليد أخضر تدريجي (PWM)، وليد أحمر للتحذير، وبازر صوتي.

## فكرة عمل المشروع
يعتمد المشروع على قياس المسافة بين الحساس وأقرب عائق أمامه، وتغيير التنبيهات البصرية والصوتية حسب المسافة:
- أبعد من 50 سم: إضاءة كاملة لليد الأخضر ومؤشر الـ Bar Graph.
- بين 50 سم و 10 سم: خفوت تدريجي لإضاءة الليد الأخضر وتناقص عدد ليدات الـ Bar Graph كلما اقترب العائق.
- 10 سم أو أقل: إطفاء المؤشر التدريجي وتشغيل الليد الأحمر.
- 10 سم أو أقل: تشغيل البازر مع استمرار الليد الأحمر.

## التوصيلات الرئيسية
- **حساس المسافة (HC-SR04):**
  - TRIG ← Pin 9
  - ECHO ← Pin 8
  - VCC ← 5V
  - GND ← GND
- الليد الأخضر التدريجي (PWM): Pin 11
- الليد الأحمر: Pin 7
- البازر: Pin 6
- مؤشر الـ LED Bar Graph: Pins 2, 3, 4, 5, 10 مع مقاومات حماية وخط GND مشترك على البريد بورد.
